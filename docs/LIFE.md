# Моя жизнь

Раздел доступен в основном меню и по адресу `#life`. Тёмный стиль, выбранный акцент и настройки анимации продолжают действовать. Вкладки имеют прямые ссылки: например, `#life?tab=finance` и `#life?tab=nutrition`.

- **Обзор:** завершённые задачи, дни достижения целей привычек, среднее настроение по дневнику и минуты внесённых тренировок за 7/21/30/90 дней. Приоритеты текущей недели, прогресс целей, финансы текущего месяца, запись шагов/тренировок/веса, фраза дня и выбранная иллюстрация.
- **Моя неделя:** семь дней с общими задачами планера; до пяти приоритетов, фокус, радости, награда и вопросы для обзора. Дедлайны из проектов и важные задачи. Тот же трекер привычек: дневную цель можно отметить или сбросить; будущие дни недоступны. Значения счётчика можно точнее настроить в разделе «Привычки». Итоги недели сохраняются отдельной кнопкой.
- **21 / 90 дней:** цель, сфера, дата начала, зачем, награда, редактируемые шаги и связанные привычки. Процент = выполненные шаги / все шаги; течение времени не добавляет процент выполнения. Последний день включён в период. Для привычек показывается число достигнутых дневных целей в прошедшей части периода.
- **Психология:** одна редактируемая запись на дату: настроение 1–5, напряжение 0–10, эмоция, мысли, благодарности, потребности и бережный шаг. Графики и средние за семь дней. Разбор мыслей: «Всё из головы», «Убрать», «Решить», «Сделать», «Пока оставить». Мысль можно редактировать, перенести и превратить в обычную задачу. Повторное создание той же задачи блокируется, пока она существует. Изменение текста мысли не переписывает уже созданную задачу.
- **Баланс сфер:** удовлетворённость шестью сферами, важность 1–5, история оценок. Ноль в ползунке означает «нет оценки»; в среднем участвуют оценки 1–10. Колесо замыкается при заполнении всех сфер. Изменение средней оценки показывается только для двух полных обзоров.
- **Питание:** фактически съеденные блюда по дате, приёму пищи и порции; необязательные калории, белки, жиры и углеводы, объём воды и недельный график. КБЖУ относятся ко всей записанной порции, не к 100 г. Собственные ориентиры необязательны. В рецепте кнопка «В дневник: 1 порция» записывает приблизительную калорийность одной порции, независимо от числа порций при готовке. Планирование меню не считается съеденной едой. Вода в мл не конвертируется автоматически в произвольные единицы привычек.
- **Финансы:** ручные операции доходов и расходов в рублях, дата, собственная категория, комментарий, редактирование, удаление, поиск, выбор месяца, лимит расходов, разбивка по категориям и график расходов по дням. Суммы хранятся целыми копейками. Разница доходов и расходов не является балансом банковского счёта. Подключения к банкам нет.
- **Вдохновение:** авторская фраза дня (одинаковая для одной календарной даты на устройствах), избранные и собственные редактируемые фразы, шесть оригинальных иллюстраций. Карточку можно выбрать в обзор и скачать как SVG.

Пропущенные записи и неизвестные питательные значения не подменяются нулями. В каждом графике есть раскрываемые текстовые данные. Психологические наблюдения не используются для диагнозов, а питание — для автоматического назначения норм и диет.

## Сохранение и совместимость

Новые данные находятся в `AppState.life` и используют существующие IndexedDB, JSON-экспорт/импорт и синхронизацию Supabase. Старые резервные копии версии 1 читаются: недостающий `life` заполняется пустой структурой. Личные данные по умолчанию пусты. Дополнительный SQL не требуется: существующая таблица хранит весь документ в JSONB, права RLS продолжают действовать.

Вход на всех устройствах должен быть в один аккаунт. Без входа данные доступны только в данном браузере. После первого онлайн-запуска production-сборка кэширует также новый раздел и все шесть иллюстраций. Записи можно изменять без сети; синхронизация возобновляется после подключения. Независимые записи и изменения разных полей объединяются, конфликтующие правки требуют выбора версии в настройках.

Перед использованием новых разделов обновите VSPACE на остальных устройствах: старый клиент не знает новых полей. При появлении уведомления об обновлении сначала сохраните открытые формы, затем нажмите «Обновить». Резервная копия из настроек включает все новые разделы.

Проверки: `tests/life.test.ts` (совместимость, суммы, реальные расчёты, пропуски и слияние), `tests/e2e/life.spec.ts` (сценарии ввода, редактирования, удаления и перезагрузки, адаптивность), `tests/e2e/cloud.spec.ts` (компьютер/телефон с изолированными браузерными профилями и тестовым HTTP API, включая правки без сети). Проверка PWA открывает новый раздел и иллюстрации и сохраняет воду без сети. Реальное подключение к пользовательскому Supabase проверяется отдельно; тесты не отправляют личные записи на сервер.
