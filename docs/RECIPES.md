# Пополняемая книга рецептов

В разделе «Рецепты» есть три режима:

- **Все рецепты** — шесть встроенных рецептов и личная книга. Поиск по названию и ингредиентам, фильтр категории и избранного работают без сети.
- **Моя книга** — сохранённые из каталога и собственные рецепты. «Добавить рецепт» позволяет записать найденный на любом сайте рецепт с ингредиентами, шагами и ссылкой. Ссылка сама по себе не импортирует страницу: текст нужно внести в форму.
- **Международный каталог** — поиск в публичном API TheMealDB по названию; если совпадений нет, поиск по ингредиенту с загрузкой полных рецептов. Каталог на английском. Несколько распространённых русских запросов («курица», «рис», «лосось» и т. д.) переводятся словарём; это не универсальный переводчик. Любой другой запрос можно ввести по-английски. Результат открывается в приложении с оригинальными шагами и количеством ингредиентов, ссылкой на источник и кнопкой «Сохранить в мою книгу».

«Найти в Яндексе» открывает русскоязычный поиск в новой вкладке с текущим запросом. Внешние страницы не скачиваются и не копируются автоматически. Можно сохранить нужный рецепт в своей книге через форму.

В международном режиме кнопки «Завтрак / Обед / Ужин» выбирают категорию сохранения, а не фильтруют сторонний каталог. Рецепты с категорией Breakfast в источнике распознаются как завтрак. Категорию можно поменять при редактировании сохранённого рецепта.

Добавление найденного рецепта в избранное, меню или дневник питания также сохраняет полный рецепт, чтобы ссылка из меню работала после перезагрузки и без сети. Повторное сохранение не создаёт дубликат. Время, порции и калории, которых нет у источника, остаются `null`. КБЖУ не рассчитываются из названия или списка ингредиентов. Количества международных и собственных рецептов сохраняются текстом; автоматического пересчёта ложек, дробей и других произвольных единиц нет. В дневнике можно уточнить размер съеденной порции и пищевую ценность вручную.

Удаление собственного рецепта с подтверждением также убирает его из меню и избранного. Уже внесённые записи дневника питания сохраняются: это история съеденных блюд, а не ссылки на рецепт.

## Данные и доступность

`AppState.savedRecipes` — массив полных рецептов с ID. Он использует существующие IndexedDB, JSON-резервные копии и слияние Supabase. Старые резервные копии загружаются с пустой личной книгой; дополнительный SQL не требуется. На устройствах нужно обновить приложение и войти в один аккаунт. Лимит личной книги — 500 рецептов, общий лимит резервной копии и облачного документа — прежние 5 МБ.

Приложение читает TheMealDB напрямую из браузера по HTTPS, без отправки профиля, дневника или авторизационных данных VSPACE. Запрос требует интернета и доступности стороннего API. Лимит ожидания — 20 секунд; ошибки не удаляют сохранённые рецепты. Поиск не запускается на каждую букву. Устаревший запрос отменяется при изменении ввода или режима, результаты очищаются. Сервисный ключ Supabase для этого не используется.

Реализован вариант пополнения через поиск и сохранение. Еженедельной автоматической загрузки 2–3 рецептов в каждую категорию и фонового расписания нет.

В этой облачной среде прямой доступ к TheMealDB закрыт сетевым прокси. Поиск, пустые ответы, ошибки, нормализация и сохранение проверены с тестовыми HTTP-ответами, а сохранение на двух устройствах — с тестовым облаком. Проверка live-доступности API из пользовательской сети остаётся отдельной от тестов. Сохранённая книга не зависит от доступности каталога.
